# 쿠팡 파트너스 가입·운영 정리 (마이펫)

조사일 2026-11-19. 「포털」 = partners.coupang.com 가입·정산·링크 화면 문구(로그인 전 공개 스크립트에서 확인). 「가이드」 = 쿠팡이 만든 [이용 가이드 v.1(2021-07, 블로그에 올라온 사본)](https://blog.kakaocdn.net/dn/qj7jV/btrjD2lm1wl/QX41x55oEs1xPOXLUI7r50/tfile.pdf). 약관·운영정책 원문은 열어 보지 못했다.

## 결론 (5줄)

1. **「개인 사업자(세금계산서 미제공)」**로, 카이랩 사업자번호를 넣어 가입한다.
2. 포털이 「간이 과세자는 세금계산서 발행이 불가능하니 개인 사업자로 선택」하라고 안내한다. 국세청도 4,800만 원 미만 간이과세자는 영수증만 발급한다고 한다.
3. 받는 방식은 「개인」과 같다(3.3% 떼고 입금). 세금계산서 일이 없고, 수익이 카이랩 쪽 기록으로 잡힌다.
4. 개인 ↔ 개인 사업자(미제공)는 포털에서 직접 바꿀 수 있다. 「세금계산서 제공」형으로 가는 메뉴는 없다 → 매출이 4,800만 원을 넘으면 그때 고객센터에 묻는다.
5. 직장이 있으면 어느 유형이든 5월 종합소득세에 근로소득과 합산해 신고한다. 회사 겸업 규정은 따로 확인한다.

## 1. 개인 vs 사업자

| 유형 | 준비물 | 지급 |
|---|---|---|
| 개인 | 본인인증·계좌 | 원천세 떼고 입금 |
| 개인 사업자(미제공) | 사업자등록증·통장 사본, 업태/종목 | 개인과 같음 |
| 법인/개인 사업자(제공) | 위 + 범용 공동인증서 | 수익 + 부가세 10%. 쿠팡이 **역발행**한 세금계산서를 기한 안에 승인해야 지급 |

- 원천세 = 사업소득세 3% + 주민세(그 금액의 10%)(포털).
- 국세청: 4,800만 원 미만 간이과세자는 영수증만 발급한다(세금계산서를 내려면 간이과세 포기). 이 구간은 부가세 납부도 면제된다. 간이과세 기준은 1억 400만 원이고, 신고는 연 1회(1월 25일까지)다([국세상담센터](https://call.nts.go.kr/call/qna/selectQnaInfo.do?mi=1329&ctgId=CTG11937), [국세청](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7693&mi=2272)).
- 유형 변경 메뉴는 「개인 → 개인 사업자」 「개인 사업자 → 개인」뿐이다. 미제공 ↔ 제공은 계정을 새로 만들어야 한다는 고객센터 답변이 블로그에 있다([세무 Q&A](https://www.findsemusa.com/service/consult/consultView.do?qidx=20838), 비공식).
- 직장인: 「근로소득 연말정산을 하였더라도 … 사업소득 … 합산하여 신고」([국세청](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=40483&cntntsId=238978)).

## 2. 여러 사이트

- 링크를 걸 웹사이트를 **모두** 등록한다(최소 1개, 가입 뒤 「계정관리」에서 추가). **등록하지 않은 채널에서 활동하면 부정행위로 볼 수 있다**(포털).
- **채널 아이디**(8~20자 영문·숫자)를 만들면 사이트별 실적을 나눠 볼 수 있다.
- 최종 승인 때 사이트마다 링크·문구가 보이는 스크린샷을 올린다(가이드).

## 3. 링크 종류

- 「간편 링크 만들기」는 **제품 상세·검색결과·기획전 URL만** 받는다(포털).
- 「소형견 하네스」 같은 `coupang.com/np/search?q=…` 검색 링크는 **된다**.
- 카테고리 페이지는 안 된다 → 「카테고리 배너」(반려동물용품 있음)를 쓴다.

## 4. 이미지·가격

- 공식 방식: 「이미지 + 텍스트」 HTML, 다이나믹 배너·검색 위젯(iframe/JS), API의 상품 정보.
- 이미지를 내려받아 다시 올리는 것과 가격 표시를 다룬 파트너스 조항은 **찾지 못했다**. 가이드는 저작물 무단 복제와 쿠팡 로고·로켓배송 이미지 사용을 금지한다.
- 안전한 쪽: 검색 카드는 텍스트로만 만든다. 상품 이미지는 받은 URL을 그대로 쓰고, 가격은 빼거나 기준 시각을 함께 적는다.

## 5. 대가성 문구

- 쿠팡 지정 문구: **「이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.」** 빠지면 최종 승인이 반려된다(포털·가이드).
- [추천·보증 심사지침(현행 예규 제499호)](https://www.law.go.kr/LSW/admRulInfoR.do?admRulSeq=2100000280130):
  - 문자 게시물은 **제목 또는 첫 부분**에 본문과 구분되게 둔다(글자를 더 크게 하거나 색을 다르게).
  - 추천 내용 가까이 두고, **매 건마다** 표시한다.
  - 「더보기」·링크를 눌러야 보이거나, 글자가 너무 작거나, 배경과 색이 비슷하면 부적절할 수 있다. 「AD」 「PR」은 안 된다.
- 2024-12-01 개정으로 「끝 부분」 선택지가 없어졌다. 구매 링크 수수료처럼 대가를 나중에 받아도 표시 대상이다([정책브리핑](https://www.korea.kr/news/policyNewsView.do?newsId=148936506), [공정위 안내서](https://www.ftc.go.kr/www/selectBbsNttView.do?bordCd=3&key=12&nttSn=46709)).
- 지침에 「웹사이트」 항목은 따로 없다 → 블로그 기준을 그대로 적용(해석): 카드가 있는 페이지마다 **제목 바로 아래 + 카드 묶음 바로 위**에 둔다. 푸터만으로는 부족하다.

## 6. 금지 행위

- **자동 이동·보이지 않는 링크(납치광고):** 쿠팡이 형사 고소했다. 1회 위반만으로도 수익을 장기간 몰수하고, 2회 이상이면 계정을 해지할 수 있다([쿠팡 뉴스룸](https://news.coupang.com/archives/57068/)).
  - 근거 조항은 포털의 「운영정책 제4.2 이용 제한 정책」이다.
  - 금지 4유형(기술적 금지·무효 클릭 유도·인위적 노출·방문자 경험 저해)과 14일/30일 몰수는 보도에만 있다([더쎈뉴스](https://www.mhns.co.kr/news/articleView.html?idxno=741357)).
  - 숨긴 iframe·쿠키 심기도 여기에 들어갈 것으로 보이지만 원문은 확인하지 못했다.
- 더보기·플로팅 배너는 2025년 1월 금지됐다고 보도됐다([모비인사이드](https://www.mobiinside.co.kr/2025/01/22/coupang-partners/)).
- 「쿠팡」이 들어간 도메인, 로고 사용, 상관없는 글에 댓글로 링크 다는 것도 금지다. 허위·과장은 이용약관 제15조에 따라 즉시 제한된다(가이드).
- 「최저가」·지난 가격·본인 구매를 다룬 공식 조항은 확인하지 못했다(최저가는 표시광고법 위반 소지).
- 메신저: 가이드는 금지가 아니라 「앱 리스트 URL」로 채널 등록하라고 안내한다.

## 7. API

- 기능: 상품 검색·추천, 딥링크 변환, 실적 리포트. 호출에 HMAC 서명이 필요하다.
- **API 키는 최종 승인 회원만 발급**(포털). 가이드에는 최종 승인이 **매출 15만 원 이상**이 난 뒤 시작된다고 되어 있다(현재 기준은 미확인).
- 키는 서버에서만 쓴다.
- 호출 한도: 가이드에는 Search 시간당 10회로 적혀 있다. 2025년 개발자 글은 분당 50회로 바뀌었다고 한다([인프런](https://www.inflearn.com/en/community/questions/1524872), 비공식).
- 처음에는 API 없이, 간편 링크로 만든 검색 링크를 고정해 두고 시작한다.

## 8. 수수료·정산

- 거래액의 **3%**(가이드). 지금은 상품별 요율이 있으니 로그인 뒤 「수익 지급율」 메뉴에서 확인한다.
- 링크로 **들어온 시각부터 24시간** 안에 산 것까지 인정된다(가이드).
- 5월 실적 → 6/25 정산 → **7/15 지급**. 지급은 최종 승인 + **누계 수익 1만 원 이상**일 때부터, 월 상한은 3,000만 원이다(포털).
